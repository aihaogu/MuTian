## 颜色

| 名称 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 宣纸 `detailBackground` | `#F5F1E7` | `#1B1917` | 窗口底色 |
| 侧栏 `sidebarBackground` | `#ECE6D9` | `#151412` | 侧栏，比宣纸深一层 |
| 笺 `paper` | `#FCFAF4` | `#262320` | 卡片、阅读区 |
| 墨 `ink` | `#2A2522` | `#ECE5D8` | 标题与正文 |
| 淡墨 `controlInk` | `#554E47` | `#8F8578` | 按钮、分段控件等普通控件 |
| 朱砂 `cinnabar` | `#B3312A` | `#DC6152` | 眉题、选中标记、收藏、错误、主要操作 |

四部沿用《四库全书》书衣配色：经绿 `#4D7A5B`、史红 `#A8412F`、子蓝 `#34598A`、集灰 `#7A756C`；四部之外用赭 `#96693A`。印章和书衣用固定色值，深浅模式下不变；统计色条在深色模式下用提亮的版本。

朱砂的使用范围要守住：普通按钮、图标、分段控件一律用淡墨。全局 `.tint` 是 `controlInk`，需要朱砂的地方单独指定。

## 字体

- 标题、书名、数字：宋体，`Font.song(size, weight:)`（中文落在 Songti SC，西文和数字落在 New York）。
- 说明文字、控件：系统字体。
- 题签：楷体 `MuTianTheme.brush(size)`；系统没有安装楷体时退回宋体。

## 组件

- `SealMark`：朱底白文小印。双字竖排用于侧栏的“木天”，单字用于四部（经、史、子、集、外、未）和收藏（藏）。
- `PageMasthead`：页首。朱砂小字眉题、30 pt 宋体标题、文武线。页面有页首时用 `hidingToolbarTitle()` 隐藏工具栏里重复的标题。
- `WenWuRule`：文武线，一粗一细，取自古籍版框。
- `SectionHeading`：节标题，细线延伸到右侧，可带前置小印和右侧附件。
- `StatusBadge`：签条式状态标记。
- `muTianPanel()`：笺色卡片。
- `paperScrollEdge()`：内容滚到工具栏下方时渐隐到纸色。

## 几处实现上的取舍

- 侧栏选中态是自绘的（淡墨底加一道朱砂），不使用系统的强调色高亮，所以侧栏的行是按钮而不是 `List(selection:)`。代价是不能用方向键在侧栏里逐行移动。
- 工具栏背景设为隐藏，窗口背景设为宣纸色（`PaperWindowBackground`），侧栏和内容区各自的底色才能一直铺到窗口顶部。
- 线装书衣按书所在的部取布色，未分类用瓷青 `#33475B`；题签只取书名里的文字和数字。
