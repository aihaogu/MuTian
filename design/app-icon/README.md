# 木天应用图标 · 四部书阁

2026-10-29 设计的备选图标。**目前没有使用**：2026-11-10 正式图标改回「朱砂藏印」，本目录留作设计记录。当时导出的 PNG 和 icns 存放在 `export/`；想再次启用时，按下文「更新应用图标」把它们放回 `MuTian/Resources/`。

## 构成

- 书阁：屋檐、横梁和台基组成藏书楼的剪影。「木天」原指秘阁、翰林院，也就是藏书之所。
- 四册线装书依《四库全书》书衣配色：经部绿、史部红、子部蓝、集部灰。
- 书册画的是正面：装订在右，题签在左上。题签留白不写字（2026-10-29 修订）：写上经史子集后，Dock 尺寸下字只剩几个像素，糊成一团；靠四色书衣区分四部，画面更清爽。

## 文件

- `mutian-icon.svg`：完整版母版，1024 × 1024，按 macOS 图标网格（824 px 圆角底板，四周留 100 px）。
- `mutian-icon-small.svg`：小尺寸简化版，去掉正脊、台基合成一条，用于 64 px 及以下。
- `build_svg.py`：生成以上两个 SVG 的脚本，只用 Python 标准库。

## 更新应用图标

1. 把两个 SVG 各导出成 1024 × 1024 的透明底 PNG，分别覆盖 `MuTian/Resources/AppIconSource.png` 和 `MuTian/Resources/AppIconSourceSmall.png`。注意 macOS 自带的 SVG 渲染（NSImage / Quick Look）不支持底板阴影滤镜，用它导出时要另外补上阴影（高斯模糊 14 px、下移 12 px、不透明度 28%）。
2. 运行 `python3 scripts/generate_app_icon.py`，生成 `AppIcon.iconset` 和 `AppIcon.icns`。64 px 及以下的尺寸会自动改用简化版源图。
