木天 v1.0 是首个正式发布版本，提供本地古籍的整理、检索、阅读与下载导入。

## 下载与安装

- 系统：macOS 14 或更新版本。
- 安装包：`MuTian-v1.0-macOS-arm64.zip`，适用于 Apple Silicon（M 系列芯片）。本次未提供 Intel 安装包。
- 解压后将 `木天.app` 拖入“应用程序”，再启动应用；无需另外安装 Python 或 Go。
- 本版本采用临时签名，尚未进行 Developer ID 签名及 Apple 公证。首次启动可能被 macOS 拦截；确认下载来源与校验值后，可按系统提示在“系统设置 → 隐私与安全性”中允许打开。
- `SHA256SUMS.txt` 用于校验压缩包；`BUILD_INFO.txt` 记录源码提交、架构与构建工具版本。

## 主要功能

- 本地文件夹扫描与多格式导入，四库分类、封面/列表浏览、书目信息编辑、收藏、搜索筛选与统计。
- 资料库文件夹管理、路径修复、索引备份恢复，以及阅读位置与页面记录保留。
- PDF、图片序列、文本及 EPUB 阅读；PDF/EPUB 目录、独立阅读窗口、单双页、连续/分页、阅读方向及缩放设置。
- 下载任务配置、日志、取消、校验后重试，以及下载完成后的资料库导入。
- 内置 Python 下载引擎、运行环境和 HTTPS 根证书。

## 使用与限制

完整步骤和真实界面截图见 [README](https://github.com/aihaogu/MuTian/blob/v1.0/README.md)。

- 书籍文件由用户自行导入，安装包不包含截图中的古籍资料库。
- 当前下载引擎尚未覆盖原 Go 版 bookget 的全部站点；登录、验证码、DeepZoom/瓦片拼接仍有限制。
- DJVU、UVZ、MOBI、AZW3、ZIP 等格式可索引，内置阅读尚不支持。
- OCR 识别、全文索引、自动校对及版本比对尚未实现。
- 自动化验证覆盖构建、迁移、阅读解析、资料库/下载状态与离线下载，不等于全部真实网站或全部 macOS 版本的验收。

## 升级与数据

升级前正常退出旧版，并备份 `~/Library/Application Support/木天/` 及实际古籍文件目录。替换应用不会主动删除这些目录。已有“得古”资料的迁移规则见 README。

数字古籍下载能力源自 [deweizhu/bookget](https://github.com/deweizhu/bookget)，相关来源说明和许可证随源码及应用包保留。
